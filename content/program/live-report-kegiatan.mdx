# Live Report Dokumentasi Lapangan

Liputan interaktif secara real-time melalui Instagram Story pada setiap penugasan siaga medis, pelatihan, dan aksi bakti sosial.

### Fokus Program
- Menyajikan transparansi dan atmosfer kegiatan lapangan kepada publik.
- Mengabadikan rekam jejak pengabdian relawan KSR PMI Tel-U di setiap acara.
